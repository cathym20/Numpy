# NumPy Statistical Analysis

This project demonstrates basic numerical data analysis using NumPy.

## Features
- Generated a 2D numeric dataset using NumPy
- Computed mean, median, min, max, variance, and standard deviation
- Calculated covariance and correlation matrices
- Performed column-wise and row-wise aggregations using axis operations

## Tools
- Python
- NumPy

## What I Learned
- How NumPy handles multidimensional arrays
- Difference between axis=0 and axis=1
- Vectorized statistical computations
